FAQ

คำถามที่พบบ่อย

ถ้ายังมีอะไรค้างอยู่ในใจก่อนตัดสินใจ ลองดูตรงนี้ครับ

  • หนังสือเล่มนี้ไม่ได้เปลี่ยนคุณเป็นคนพูดเก่ง แต่ให้ Framework และ Guidemap ที่ช่วยให้คุณประเมินสถานการณ์ตรงหน้า และเห็นทางเลือกว่าควรคุยต่ออย่างไร
  • เป้าหมายคือให้คุณมีแผนที่ช่วยตัดสินใจ โดยยังชวนคุยในแบบที่เป็นตัวเองได้ครับ
  • ไม่ต้องครับ หนังสือไม่ได้ให้ Script สำเร็จรูปไว้ท่องจำหรือบังคับคำพูด
  • แต่ให้ Framework และแผนที่นำทาง เพื่อให้คุณตัดสินใจได้เองตามบริบทของบทสนทนาจริง
  • ไม่ครับ หลักในเล่มใช้ได้กับการเริ่มคุยในหลายสถานการณ์
  • ไม่ว่าจะเป็นเพื่อนใหม่ เพื่อนร่วมงาน งาน Networking หรือคนที่อยากทำความรู้จัก
  • ความประหม่าอาจยังมีอยู่ แต่คุณจะไม่ต้องประหม่ากับการประดิษฐ์คำพูดสดใหม่ทุกจังหวะ
  • Framework และ Guidemap จะช่วยให้คุณมองเห็นทางเลือกว่าในจังหวะนั้นควรเริ่มต้นอย่างไร และควรพาบทสนทนาไปทางไหนต่อครับ

Guidebook คือเนื้อหาหลัก PDF 57 หน้า สำหรับอ่านเพื่อทำความเข้าใจ Framework ทั้งหมด ส่วน Guidemap คือสรุปแผนที่พร้อมใช้ 2 ชุด สำหรับเปิดดูทางเลือกเร็วๆ เมื่ออยู่ในสถานการณ์จริงครับ

เป็น E-Book ไฟล์ PDF เปิดอ่านได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์ครับ

หลังชำระเงิน สามารถดาวน์โหลดไฟล์ได้ทันที และระบบจะส่งไฟล์เข้าอีเมลของคุณโดยอัตโนมัติครับ
